# 춘삼마을 런처 | Chunsam Village Launcher

춘삼마을 Minecraft Java 서버를 위한 비공식 커뮤니티 런처입니다.

Chunsam Village Launcher is an independent Windows launcher for the Chunsam Village Minecraft Java server. It is based on MRS Launcher 3.0.9 (MIT license).

- Game: Minecraft Java Edition 26.3 with Fabric
- Server: `christmas1225.p-e.kr`
- Sign-in: Microsoft account authentication through Microsoft Entra, Xbox Live, and Minecraft Services
- Community content: announcements and Fabric mod updates managed through this GitHub repository
- Application (client) ID: `0d433033-ce35-49a2-8930-ac73e9308a88`

The launcher is intended for players who own Minecraft Java Edition. It asks Minecraft Services to authenticate the player's account and retrieve the player's game profile. Access for this application ID is pending Minecraft AppID review.

This is a community project and is not affiliated with or endorsed by Microsoft, Mojang, or Minecraft.
